# MyFindDroid

本仓库是 [Findroid](https://github.com/jarnedemeulemeester/findroid) 的个人分支（fork）。Findroid 是 Jellyfin 的第三方 Android 客户端，提供原生界面用于浏览和播放电影/剧集。

上游项目完整的功能介绍、截图、翻译、构建命令、许可等信息，请直接参考官方仓库及其 README：

- 官方仓库：<https://github.com/jarnedemeulemeester/findroid>
- 官方文档：<https://github.com/jarnedemeulemeester/findroid/blob/main/README.md>

本文件不再重复官方说明，仅介绍本分支在原版基础上新增与优化的体验。

## 本分支特色功能

### 首页与浏览

- **轮播自适应屏幕**：首页顶部轮播会随屏幕宽度自动调整单屏显示数量与宽高比，手机、平板、大屏上都排得刚刚好。
- **视觉比例统一**：「继续观看」和媒体库封面沿用与轮播一致的宽高比，整页观感更协调。
- **海报完整展示**：详情页背景图按原图比例完整铺开，不再被裁掉两侧画面。

### 详情页

- **标题可折叠**：过长的标题默认收起三行，点击即可展开或收起，详情页更清爽。
- **文件路径可见**：电影详情页直接展示文件的本地与服务器存放路径，长路径一点展开，方便定位片源。
- **下载项详情**：下载页面会为每个已下载媒体项提供信息入口，随时查看标题与本地文件路径。

### 播放体验

- **亮度记忆更聪明**：只有你手动调节过亮度才会记忆并沿用，从未调节时保持系统亮度，不再莫名变暗。
- **控制栏更顺手**：播放控制栏背景改为透明、按钮改为左下角对齐，画面不被遮挡，操作更紧凑。

### 兼容与稳定

- **兼容老服务器**：放宽最低版本要求，可正常连接 Jellyfin 10.10.x 服务器。
- **引导不再崩溃**：修复添加服务器与登录时的网络异常，首次接入流程更稳定。
- **列表不再错乱**：修复特定排序下媒体列表偶发的重复项报错，浏览更流畅。
- **日志统一**：应用日志统一归类，遇到问题时可一键过滤全部日志，便于反馈与排查。

## 与上游同步

本分支会不定期将上游 `main` 的更新合并进来，同时保留上述自定义改动。若需要上游的原生功能说明，请以上文官方仓库为准。
