# MyFindDroid

本仓库是 [Findroid](https://github.com/jarnedemeulemeester/findroid) 的个人分支（fork）。Findroid 是 Jellyfin 的第三方 Android 客户端，提供原生界面用于浏览和播放电影/剧集。

上游项目完整的功能介绍、截图、翻译、构建命令、许可等信息，请直接参考官方仓库及其 README：

- 官方仓库：<https://github.com/jarnedemeulemeester/findroid>
- 官方文档：<https://github.com/jarnedemeulemeester/findroid/blob/main/README.md>

本文件不再重复官方说明，仅介绍本分支在原版基础上新增与优化的体验。

## 本分支特色功能

### 首页与浏览

- **轮播自适应屏幕**：首页顶部轮播会随屏幕宽度自动调整单屏显示数量与宽高比，手机、平板、大屏上都排得刚刚好。
- **视觉比例统一**：「继续观看」和媒体库封面沿用与轮播一致的宽高比，整页观感更协调。
- **海报完整展示**：详情页背景图按原图比例完整铺开，不再被裁掉两侧画面。
- **封面形态可切换**：媒体库排序弹窗里可在竖图（海报）与横图（剧照）之间切换封面展示形态，想细看剧照时更直观。
- **排序支持随机**：媒体库排序菜单新增「随机」一项，随机模式先取回一批再本地打乱分页，不会出现重复条目，选中后自动禁用排序方向按钮。
- **按元数据浏览**：「我的媒体」页底部新增浏览入口，可沿类别、标签、分级、年份、演员、导演、编剧、制片公司逐层查看——先列出该维度的全部取值（人物维度可按名字搜索），点进去即是该取值下的作品列表，同样支持排序与封面形态切换。
- **搜索框更顺手**：搜索框的加载指示器与清除按钮并列显示、不再互相挤掉；搜过的关键词结果会缓存，来回切换时不用重新等待。
- **下拉刷新重载轮播**：首页下拉刷新会强制重新拉取顶部轮播；平时从详情页返回不再重拉，避免轮播重建、封面重新加载导致整页像被刷新一遍。

### 详情页

- **标题可折叠**：过长的标题默认收起三行，点击即可展开或收起，详情页更清爽。
- **文件路径可见**：电影详情页直接展示文件的本地与服务器存放路径，长路径一点展开，方便定位片源。
- **下载项详情**：下载页面会为每个已下载媒体项提供信息入口，随时查看标题与本地文件路径。
- **「更多」菜单**：电影详情页新增「更多」操作，可编辑封面、编辑 nfo 元数据（标题、原名、简介、类型、标签、制片厂、评分等），也可连同视频文件一起删除；都会改动服务器内容，故各自还有二次确认。
- **封面可编辑**：编辑封面时用小图列出该条目在服务器上当前正在使用的图片，点击可全屏查看（支持双指缩放，也可就地上传这一张）；右上角「清理」二次确认后删光所有图片；左下角「抓取」会按番号把配置过的站点都抓一遍，结果显示在同一个弹窗里——每个站点一行，失败的给出原因，成功的列出横图与竖图并在行末给「上传」按钮（上传会先删掉服务器上同类型的旧图，再写入新图）。
- **nfo 可抓取**：编辑 nfo 时能按番号到 ***一些常见网站*** 抓取标题、简介、类型、日期、评分等并回填表单，抓取只在手机上取文字，确认后才写入服务器；站点地址由本机 `local.properties` 配置（不入库），未配置的站点会跳过，也可在抓取弹窗里单设代理。表单里还能直接填写演员与导演。
- **抓取结果可翻译**：抓回来的标题与简介（或表单里现有的内容）可调用大模型翻译成简体中文，走 OpenAI 兼容的对话接口、默认 DeepSeek，接口地址、密钥与模型保存在本机，没填齐就自动跳过；也可设为抓取后自动翻译。
- **合集封面与角标**：合集在服务器上常无自带图片，会自动借用内部条目的图片作封面；合集卡片带角标，和普通影片放一起也能一眼区分。

### 演员与人物

- **点演员直达作品**：不再单独打开人物详情页，点击演员 / 导演 / 编剧直接列出其名下作品，少一次跳转；列表加载失败会显示错误卡片并可重试。
- **头像可抓取**：长按演员卡片或详情页的演员条目会弹出「获取头像」，按名字去已配置的站点抓候选头像，选好后上传替换（该演员已有头像时先给出提示）。

### 播放体验

- **亮度记忆更聪明**：只有你手动调节过亮度才会记忆并沿用，从未调节时保持系统亮度，不再莫名变暗。
- **控制栏更顺手**：播放控制栏背景改为透明、按钮改为左下角对齐，画面不被遮挡，操作更紧凑。
- **多版本任选**：同一部影片存在多个文件（多版本）时，播放前会弹窗让你选择要播的版本，并用图标区分本地文件与服务器文件。
- **右上角菜单与截图设封面**：字幕、倍速、音轨三个按钮收进右上角菜单；菜单里新增「截取当前画面设为横屏封面」，一键把当前画面截成剧照上传（服务器已有剧照时会提示先删除，离线模式下不显示该入口）。

### 下载

- **后台持续下载**：下载改由 WorkManager 前台服务驱动，退出下载页面后仍会继续，通知栏可见进度。
- **多分片并发加速**：大文件在服务器支持断点续传时自动切成多段并发下载，跨公网、高延迟链路明显更快；探测到不支持时自动退回单连接，不影响功能。
- **实时速度与状态**：下载卡片显示实时速度，并区分排队、暂停（含等待网络、退避重试）、失败、完成等状态，进度未知时显示为未知而非 0%。
- **可续传**：中断后重新下载会从已完成的字节继续，不会从头再来。

### 兼容与稳定

- **兼容老服务器**：放宽最低版本要求，可正常连接 Jellyfin 10.10.x 服务器。以便适配绿联nas推荐的nyanmisaka/jellyfin docker服务器。
- **稳定性**：修复常见崩溃和使用中问题
